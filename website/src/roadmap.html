0.9.0

Remote assistance,
managed centrally.

Manage people, gateways and temporary assistance sessions from the included portal, or build access into your own software through the API.

  • Gateway enrollment, individual credentials and access assigned by groups and permissions.
  • Session supervision, connection diagnostics, technical logs and gateway metrics.
  • Manual encrypted backups and guided recovery.

Current network scope

Gateway Only: the technician connects to services on the gateway's fixed VPN address. Local devices can be reached from the gateway's shell; the site LAN is not routed directly to the technician's PC.

The current focus is completing version 1.0 and validating the complete deployment on the intended hardware and networks.

Planned · design not started

2.0

Reach the authorized
site network.

Single LAN will extend an authorized assistance session to the selected gateway's local IPv4 network.

  • Use software on the technician's PC to reach devices in the authorized LAN.
  • Keep access temporary and scoped to the selected site.
  • Preserve separation between sites, including sites with matching LAN addresses.

This is planned routed Layer 3 access. It is not an Ethernet bridge, broadcast discovery or a permanent network joining multiple sites.

Architecture, compatibility and configuration workflows are still to be designed and validated.

Planned · design not started

2.1

Keep gateways
in the conversation.

MQTT will add a messaging channel between gateways and the platform, following the Single LAN release.

  • Deliver notifications to connected gateways without waiting for a periodic check.
  • Exchange status, events and telemetry through a broker.
  • Give authorized integrations a shared stream of gateway events.

MQTT will support coordination and messaging. Assistance traffic will continue to use the VPN, and a broker connection alone will not authorize access.

Broker configuration, message formats, permissions and coexistence with existing communication modes remain to be defined.
