01 / REMOTE ASSISTANCE

Access when it’s needed.
A clear beginning and end.

{{APP_NAME}} coordinates the technician, the gateway and the connection in a single, time-limited assistance session.

The included web portal manages users, groups, gateways and sessions. Gateway details show component versions, technical logs and metric history; the server page brings together service status, certificates, backups and SMTP checks.

01

Request access

An authenticated technician selects a provisioned gateway and requests a session from the {{APP_NAME}} portal or your integrated application.

02

Connect to the gateway

The gateway activates via a signed SMS or a periodic HTTPS check over Wi-Fi. The technician manually starts OpenVPN with their provisioned profile, then uses services on the gateway’s fixed VPN IP, such as SSH or web.

03

Close the session

Close access when the intervention ends. Signing out also closes VPNs opened by that portal login. Session status and timestamps remain available for your service workflow.

Different factories. Familiar network addresses.

Customer LANs can use the same IPv4 subnet because the VPN exposes only each gateway’s fixed VPN address. Reach local devices from the gateway’s SSH shell. Each technician and gateway takes part in one session at a time, including cleanup.

Your Internet connection stays local.

Gateway Only allows IPv4 traffic between the assigned technician and gateway, including TCP on custom ports, UDP and ICMP ping. Internet and DNS stay on the technician’s connection. Use the gateway’s SSH shell to reach local devices. Gateway Only access.

Time for longer interventions.

VPN sessions last up to 3 hours by default, with a 12-hour portal login. Temporary API failures preserve existing access for up to 5 minutes from the last successful authorization, within login and session deadlines. Durations are configurable; logout and revocation still apply. Durations and outage handling.

BEFORE YOU CONNECT

A gateway at the factory

A factory-prepared gateway can retrieve its individual package after administrator approval. Manual ZIP setup remains available for service and test machines. The gateway needs its services configured on the VPN IP and independent HTTPS connectivity; SMS mode also needs a SIM and an AT modem.

Access with a defined scope

Technicians manage their own sessions; administrators manage accounts and resources. Individual VPN certificates work together with session authorization.
